📊 Построитель графиков из Excel + суммы

📋 Инструкция: Выделите таблицу в Excel (включая заголовки столбцов), скопируйте (Ctrl+C) и вставьте ниже (Ctrl+V). Первый столбец станет подписями оси X, остальные — рядами данных. Первая строка — названия рядов.
🔢 Десятичный разделитель — точка (если в Excel используется запятая, замените её).
📊 Новое: В легенде теперь отображается сумма значений каждого столбца.
v1.2.0 — приложение для быстрой визуализации табличных данных с подсчётом сумм
